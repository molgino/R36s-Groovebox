# SYNTH CITY (R36S-Groovebox) – Projektkontext

Name **SYNTH CITY** (Repo `molgino/synth-city`, vorher R36s-Groovebox; interne Pfade/Binary/Dienst heißen weiter `groovebox`). Neo-Noir-/Synthwave-Optik (eigene Gestaltung, keine geschützten Film-Namen/Logos): Palette `C_*` + Neon-`TCOL`, Kopfzeilen-Linie Magenta→Cyan, Scanlines in `drawAll`, Splashscreen `drawSplash/runSplash` (Shot-Seite 40, `GB_SPLASH_T`, abschaltbar `GB_NOSPLASH`). Elektron-artige Groovebox (C++/SDL2, ALSA) für den Handheld **R36S** (RK3326, ArkOS 2.0, Kernel 4.4.189, glibc 2.30).
Sprache mit dem Nutzer: **Deutsch**. Anleitung für Nutzer: `README.md`.

## Aufbau
- `src/engine.*` Sequencer + 13 Engines (KICK SNARE HAT CLAP SYNTH FM SMPL TOM RIM SHKR WTBL CHOP GRAN – Enum-Werte nur hinten anfügen, Anzeige-Reihenfolge `MACHINE_ORDER`), Wavetables `buildWavetables`, Insert-FX, Effekt-Busse (`fxbus.cpp`), Kompressor mit Sidechain; Mikrotiming `P_MTIM` (`pend`/`preDone`, negative Werte werden einen Step früher geplant)
- `src/params.h` alle Parameter. Speicherseiten je Spur (TRG SRC FLT AMP LFO1 INS SRC2 LFO2 LFO3 SEQ FLT2 ARP SRC3 SRC4 SRC5 SEND, je 8 = 128 Parameter; `LFO_BASE`, `LF_*`) und UI-Seiten `PG_*` (TRG SEQ ARP SRC SR2 FLT FL2 AMP LF1 LF2 LF3 INS | MIX FX CMP | PRJ SNG MST SET | LIVE | SR3 SR4 SR5 SND FXB FXC; Reiter in Ring-Reihenfolge); SET (=PG_SYS) ist eine Listen-Seite (`SetItem`, `drawSettings`), Mapping `PG_STORE`; FM = 4 OP/8 Algorithmen (`FM_MODS/FM_CARRIERS/FM_LAYOUT`); globale Skala `mst[MS_SCALE]`
- `src/main.cpp` UI (640x480): Kacheln (`tile`, Wert-Symbole `paramSymbol` nach Parametername), Engine-Symbole (`drawIcon`), Engine-Wähler, Grafiken je Engine (`graphKind`), Bedienung, Einstellungen, PC-Modus-Steuerung
- `src/web.cpp` + `src/webpage.cpp` Mini-Webserver (Port 80, sonst 8080): Upload-Seite für Samples/Projekte, Umwandlung im Browser; nach Upload `reloadSamples` (Bibliothek neu lesen, geänderte Pool-Dateien neu laden). API: `/api/list` (nur Anzahl + Projekte, kein Vollscan-Listing), `/api/dir?path=` (ein Ordner: dirs mit Anzahl, files), `/api/search?q=` (max. 400), `/api/info` (WAV-Kopf), `/api/mkdir`, `/api/rmdir` (rekursiv), `/api/move?to=` (Datei/Ordner, auch Projekte umbenennen), `/api/upload` (Unterordner werden angelegt, Projekte mit freiem Namen), `/api/delete`; `safeRel` erlaubt UTF-8, sperrt `..`, Punkt-Anfang, Steuer- und FAT-Sonderzeichen; Seite pollt nicht (nur bei Aktionen/Sichtbarkeit)
- `src/remote.cpp` Bildschirm-Spiegelung + Fernbedienung: Hauptschleife legt bei Zuschauer (`remoteWanted`) max. 30/s `remoteSnapshot(fbPix)` als RGB565 ab. **WebSocket `/ws`** (`remoteWsAccept` aus web.cpp `handle`, eigener pthread je Zuschauer, max. 3, 256-KB-Stack, SHA1/Base64 eingebaut): sendet Binärbilder (Format siehe Kopf remote.cpp, Differenz je Zuschauer `RemoteClient`, neues Bild erst wenn das vorige raus ist), empfängt Text `d A`/`u A` (Taste), `a LX -1` (Achse), `p <t>` → `P <t>` (Ping), `f` (volles Bild); Abbruch lässt alle Tasten los. Rückfall ohne WebSocket: `/api/screen?since=` + POST `/api/input?b=&v=`. Seite `/screen` (WEB_SCREEN in webpage.cpp): Bild per rAF, `fit()` hält 4:3, Querformat = Bedienung links/rechts, Touch mit Pointer-Capture + Wischen (`targetsAt`, Steuerkreuz 8 Richtungen), Tastatur (`km`), Gamepad-API (`gpMap`, Lage wie R36S), Zähler je Taste (`press/release`), Wake-Lock, Vollbild; Screenshots-Test mit `GB_HEADLESS=1` + Playwright. **Touch aufs Bild**: Seite sendet `t/m/e id x y` (640x480), remote.cpp `touchPush` → `remoteTouchPop` im Hauptthread, `src/touch.inc` (`touchProcess` am Anfang von handleInput). Treffer über `hitAdd(x,y,w,h,HK_*,a,b)` beim Zeichnen (Registry `hits[]`, in drawAll geleert, `hitModal()` für Fenster darüber; Explorer/Tastatur/Editor/Export blockieren = per Steuerkreuz). Step = emuliertes A (`remoteDown/remoteHit`), Kachel ziehen = `editValue`, neue bedienbare Elemente immer mit hitAdd anmelden. **Ton im Browser**: audioCb → `remoteAudioPush` (16 Bit Stereo in Ring `g_aud`, nur bei Zuhoerern), WebSocket `/wsa` → `wsAudioThread` (Pakete u32 Rate + u32 Position + PCM, >=512 Frames, faellt > 0,25 s zurueck → springt), Seite plant AudioBufferSources luecklos (Puffer 120 ms, playbackRate ±0,4 % nachregeln); AudioWorklet geht nicht (http = kein sicherer Kontext). **Web-App**: `/manifest.json` (start_url /screen, fullscreen, landscape), Icons `src/webicons.cpp` (PNG 180/192/512), `/sw.js` nur bei https/localhost
- `src/midi.cpp` ALSA-Seq + rawmidi + USB-Seriell + RTP-MIDI (Port 5004/5005); `src/dhcpd.cpp` Mini-DHCP (`groovebox --dhcpd usb0`)
- `arkos/` Ports-Skripte, `arkos/groovebox/pc-modus.sh` (USB-Gadget: RNDIS + DHCP + SSH), `dtb-otg/` gepatchte DTBs
- Filter 1: Typen `FT_*` in params.h (nur hinten anfügen; LP12 BP HP12 LP24 LADR HP24 NTCH PEAK CMB+ CMB- VOWL), DSP `Voice::filter1`, Koeffizienten in render(), Kurven `filt1Mag` (main.cpp, auch Symbol); v10-Migration + Presets ohne hdr[6]: SYNTH/WTBL LP12 → LP24
- FM (v13): Seite SRC = ALGO FBK VELO PITCH P.DEC NOIS; Operator k auf eigener Seite ab `FM_OPB[k]` (OP1 = SRC2/`P_X0`, OP2-4 = SRC3-5) mit `OP_RAT/OP_FINE/OP_DETN/OP_LVL/OP_ATK/OP_DEC/OP_SUS/OP_REL` (`FM_OP_DEFS`, Ratio-Tabelle `FM_RATIOS` 28 Werte, alt `FM_RATIOS_OLD`), `paramDef` liefert sie fuer M_FM; Voice: `fmSt/fmAtk/fmDco/fmSus/fmRco` (Huellkurve je Operator, Zeiten `envTime` wie AMP), `fmPenv` Pitch-Huellkurve; UI-Titel `pageLong()`, Kurznamen `sigName()`, Grafik 14 (Operator-Huellkurve), `fmOpPage()`
- SYNTH-Seite OSC (SRC2): OCT1/OCT2 (`K_OCT`, 3 = 0), LVL1/LVL2, SUB.O (`K_SUBO`), SYNC (OSC2 slave), XMOD, RING; WTBL-Seite OSC: OCT, LVL, SUB.O, UWAV (`K_SMPL` auf `P_X3`, TABL 4 = USER, `wtReadUser`: Frames 2048/256/1 Zyklus), DRAW (`K_WDRAW` → `openWtEditor`, src/wtedit.inc: 4 Wellen x 64 Punkte, Vorhoeren ueber `poolSwap(PREVIEW_SLOT)`, START speichert `samples/wavetables/draw-NN.wav` 16x2048 Float); `machineSampleParam(m)` = Pool-Parameter (SMPL bzw. UWAV) fuer `poolUsed`, Presets, Explorer (`fbSmpIdx`)
- Effekt-Busse (`src/fxbus.*`, `FxBus bus[NBUS]` in Engine): Typ `BF_*` (OFF DELAY TAPE REVERB SPRING CHORUS), Regler `BUS_DEFS`/`busDef(bus,type,k)` (BX_TYPE, P1-P5, BX_FWD Weiterleitung an den naechsten Bus, BX_LVL), `Engine::setBusType`; Voice `snd[3]` → `S[3][32]` in processBlock, Busse A→B→C blockweise, Typwechsel leert ohne grosses memset (`filled`), Leerlauf je Bus (`quiet`); UI-Seiten PG_FX/PG_FXB/PG_FXC (`busOfPage`), Grafik 15, Hilfe `busHelp()` in paramhelp.h; Mixer-Zeilen `MIX_P` mit S.A/S.B/S.C; Unit-Test `testFxBus`
- Animationen (`src/anim.inc`, vor `drawPageGraph` eingebunden): `scopePush` (audioCb, Master-Stereo in `scopeBuf`), `drawScope` (Nulldurchgang-Trigger, Auto-Gain, atmet bei Stille), `specUpdate/drawSpectrum` (Goertzel, 24 Baender), `drawBeatRings`, `filler()` fuer leere Kacheln (`tile`/`miniTile` mit K_NONE); Seitengrafiken `graphKind` 16 TRIG-Piano-Roll (`trigGraph`), 17 SYNTH-OSC, 18 Wavetable-Stapel, 19 Insert, 20 Sends, 21 Bus-Animation je Typ (`busAnimGraph`); Flaechen: `settingsArt`, `songTimeline`, `liveArt`, `prjIcon`. Leere Flaeche nie leer lassen: Animation aus dem echten Audiosignal. Wert-Kacheln (`tile` global, `miniTile` Spurseiten): Name links + Zahl klein rechts in der Kopfzeile, darunter animiertes `paramSymbol` (nach Name/Kind; `symCurve` zeichnet einen wandernden Leuchtpunkt, periodische Kurven scrollen mit `symScroll()`)
- Klang: Oszillator-Drift (`drift1/2`); Drums 808/909-artig (Snare 2 Töne + Pitch-Env, Hat Zusatz-HP `hatHp`, Clap Sägezahn-Bursts). Pegel mit einem Einzelschlag-Messprogramm prüfen (Spitze ~0.3–0.5)
- Projektformat v13: 16 Speicherseiten = 128 Parameter (`NPAGES`, alt `OLD_NPARAMS` 96); neue Seiten 12-14 SRC3-5 (`P_Y0/P_Z0/P_W0`, FM-Operatoren 2-4), 15 SEND (`P_DLY`=120 Bus A, `P_REV`=121 Bus B, `P_SNDC`=122 Bus C; AMP-Slots 30/31 = `P_A6/P_A7` leer, alt `OLD_P_DLY/OLD_P_REV`); `Project.bus[NBUS][8]` statt fx[8], songOld entfallen; alte Formate v1-v12 werden in `Engine::load` erst ins 96er-Layout gelesen, dann `migrateTrack13` (Index-Abbildung `mapOldParam`, FM-Umrechnung, LFO-Ziele, Locks), Busse aus den alten fx-Werten; Groessen `OLD_PAT_SIZE`, `PROJECT_V11_SIZE`, `PROJECT_V12_SIZE`, `projectDataSize(ver)` (Sample-Trailer dahinter); Presets Format 3 (hdr[6]), aeltere ueber `migrateTrack13`. Bis v12: Index 5 = MTIM, bis v6 RFAD; Seite 10 FLT2 = Base-Width-Filter `P_BASE/P_WDTH` + `P_KEYT/P_VELF`; Seite 11 ARP `P_AMOD..P_AACC`) mit Migration v1–v9 in `Engine::load` (`remapLegacy`, v5-Zweig) – bei Strukturänderungen Version erhöhen + migrieren
- Sequencer: 12 Ticks pro 16tel (`doTick`/`stepTrack`), Tempo-Faktor `SPEED_TPS`, Trig-Bedingungen `P_COND` (`condOk`, Durchläufe `loopCount` über `stepCnt`), FILL `eng.fill`; SEQ-Seite: Richtung `P_DIR`, Euklid `P_PULS/P_EROT`, Turing-Generator `P_DENS/P_CHNG/P_RANGE` (`tmReg`), LEN/SPD zeigen auf `Pattern.len/speed`
- Arpeggiator: `Engine::Arp ar[]` in trigger() (fromSeq, nicht bei Drums), Timer im render-Block wie Retrig, `playNote()`; Song = Clip-Matrix (v12): `proj.row[i]` mit `pat[NTRACKS]` (SONG_EMPTY = Spur schweigt), `rep`, `mute`-Bits; Pattern-Mutes `proj.patMute[pat]`; Engine spielt jede Spur aus `TP(t)` = `proj.pat[patOf(t)]` (Song: `trkPat[t]` aus `applyRow`, sonst `curPat`) – nie mehr `proj.pat[curPat]` fuer Spurdaten; Mutes nur ueber `eng.muted/toggleMute/setMute` (Song: Zeile, sonst Pattern); Zeilenwechsel `rowPending` am Zeilenende in doTick, Laenge = laengste belegte Spur; UI: `curPi()`/`curP()` = Pattern der gewaehlten Spur, Pattern-Wechsel ueber `switchPattern()` (beendet Song); Seite SNG `drawSong/songInput/songEditCell` (Spalten SC_ALL, SC_T1.., SC_REP); Pattern-Mutation `mutatePattern()` mit Undo (SET)
- Trigless Locks: `Step.on` 0 leer / 1 Trig / 2 trigless; stepTrack schreibt die Locks von on==2 in `v[t].lk`/`ar[t].lk` (ohne Note/LEN/COND/PROB), gelten bis zum nächsten Trig; UI: `aPrevOn` (A antippen auf Trig mit Locks → 2, auf 2 → 1), Lock-Modus SELECT+A toggelt, B löscht (2 → 0); Raster zeichnet 2 als Umriss
- Kopieren: Trig `trigClip` (A halten + L1/R1, Zustand `aPrevOn`), Seite `pageClip[8]`/`pageClipStore` im Seitenmenü (X/Y, SRC/SR2 nur gleiche Engine, SEQ inkl. len/speed), Pattern `clip` (SET, SELECT+R1); Seitenmenü bricht Zeilen um
- Projekte `projects/<Name>.gbx` (aktives in settings.cfg `project`), Presets `presets/<ENGINE>/<Name>.gbp`

## Groovebox-OS (`os/`)
- Eigenes Image statt ArkOS: Linux `LINUX_VERSION` (gregkh/linux-Tag) + ROCKNIX-Patches/DTS (gepinnt `ROCKNIX_COMMIT`, `os/versions.env`), Panel aus ArkOS-DTB als Overlay `os/dts/panel-arkos.dtso` (generic-dsi), eigener Tree `rk3326-groovebox-r36s.dts` (OTG-Port an, usb-role-switch)
- `os/kernel/build.sh` (arm64-Runner nativ), `os/uboot/build.sh` (x86: rkbin-Tools), `os/rootfs/build.sh` (mmdebstrap Debian trixie, Overlay in `os/rootfs/overlay`), `os/image/build.sh` (MBR: U-Boot @64, GBBOOT FAT, GBROOT ext4; GROOVEBOX FAT wird beim 1. Start angelegt)
- Akku (`readBattery` alle 5 s, `battery()` in der Kopfzeile): Prozent aus `voltage_now` + `current_now`×0,15 Ω (Ruhespannung) über LiPo-Tabelle `batOcvPct`, geglaettet (`batEst`, beim Entladen kaum steigend, beim Laden nicht fallend), Treiberwert `capacity` nur Info (`batDrv`, SET „Akku“ `SI_BAT`); Laden `batPlug` = Status Charging/Full oder Mains/USB-Supply `online`; Log „Akku: …“ jede Minute; Tests: `GB_POWER_SUPPLY=<dir>` nachgebautes sysfs
- Power-Taste (evdev `rk805 pwrkey`, logind ignoriert sie): kurz `screenOff` + bl_power, lang `powerOff()` (speichern, `systemctl poweroff`); ruhiger Start (`quiet loglevel=3 panic=10`, Diagnose per extlinux.conf), Hostname `synth-city`, Kernel `-synthcity`
- Kein Initramfs: Root per `root=PARTUUID=47425653-02` (feste MBR-ID in image/build.sh), `LABEL=` geht nur im Userspace; ROCKNIX-Config hat `PANIC_TIMEOUT=1` (Panic = sofortiger Neustart) → Testphase mit `panic=60 console=tty0`
- Bild auf dem OS: `src/drmout.cpp` (make DRM=1, `GB_DISPLAY=drm`): SDL-Software-Renderer auf Surface → DRM-Dumb-Buffer (Standard: 1 Puffer direkt beschrieben, Page-Flip war langsam/springend; `GB_DRM_FLIP=1` testet Flip), SDL läuft mit Videotreiber offscreen; GPU-Weg (SDL kmsdrm/Panfrost) blieb schwarz. Umschalten per `/data/config/groovebox.env`; `present()` statt `SDL_RenderPresent`. Panel liest den RGB-Strom versetzt (Bild ~92 px verschoben + Farben rotiert) → Ausgleich `drmOutSetByteOffset` (settings.cfg `display_offset`, Standard 277 = 3·92+1, SET „Bild-Versatz“, schnelle Pixel-Variante N=off/3, r=off%3); im DRM-Modus zeichnen `fill/text/drawLine/clearScreen` direkt in `fbPix` (10x schneller als SDL-Software-Renderer, Benchmark `GB_BENCH=200 [GB_FB=1] ./groovebox --shot x.bmp 0`); eigentliche Ursache vermutlich DSI-Timing im Panel-Overlay
- App-Update ohne Image: `tools/os-update.sh` → `dist/groovebox-os-update.tgz` (groovebox DRM=1, pc-modus.sh, sbin/, VERSION; Build-Job `os-app` in build.yml, Asset im Release nightly); Wege: PUT `/api/update` (web.cpp, nur wenn /etc/groovebox-os), `/data/update/*.tgz`, deploy.ps1/.sh (erkennt `"os":true` in /api/list); `groovebox-run` installiert vor dem Start, Rollback nach 3 Fehlstarts <15 s
- Workflow `.github/workflows/os.yml` → Release **os-nightly**, läuft nur bei Änderungen unter `os/` (Nutzerwunsch: OS nicht unnötig neu bauen, App kommt per App-Update); Kernel/fremder Code nicht im Container bauen, nur in CI
- Gerät: `/opt/groovebox` (Symlinks nach `/data` = Partition GROOVEBOX), Dienst `groovebox.service`, Logs: App `/var/log/groovebox/groovebox.log` (Rootfs, sonst blockiert offenes Log das Aushängen von /data für den Laufwerk-Modus; Kopie nach /data/logs beim Beenden, enthält alle 10 s „Bild: fps…“), `/data/logs/{boot.txt,update.log}`, im Web unter „Logs“ (`/api/log?name=`); groovebox-run setzt CPU/devfreq-Governor performance, `pc-modus.sh` (aus|an|an audio|laufwerk|laufwerk-aus, configfs-Gadget RNDIS+MIDI+UAC2 bzw. Mass-Storage), SET „USB-Laufwerk“ (`startDrive/stopDrive`, nur wenn `/etc/groovebox-os` existiert); Gadget class compliant: Netz NCM (Standard, `GB_USB_NET=ncm|rndis`, SET „USB-Netzwerk“ `cfg.usbNet`/settings `usb_net`), Audio UAC2 mit `p_srate/c_srate=44100,48000` (PC wählt; `usbaudio.cpp` liest die Rate über die Regler „Playback Rate“/„Capture Rate“ (`gadgetRate`), rechnet mit Grundverhältnis `base` um und öffnet bei Wechsel neu; `usbAudioRate()`), UAC1 wählbar (`GB_UAC=1`, SET „USB-Audio-Klasse“ `cfg.uac`/`usb_audio_class`, Kernel `CONFIG_USB_CONFIGFS_F_UAC1`, sonst Rückfall auf UAC2); App übergibt beides als Umgebung (`usbEnv()` vor `pc-modus.sh`); MIDI-Schnittstelle heißt per `interface_string` „Synth City“, `bcdDevice` 0x0101. Diagnose: SET „Testton an PC“, Log „USB-Audio: … Pegel“, Web-Log „usb-diagnose“. USB-Taktausgleich: Schreib-Thread liest Ring mit geregelter Rate (Ziel 2048 Frames, ±0,2 %, Hermite-Interpolation). PC→R36S: `pcInThread` liest Gadget-Capture, `pcInMix` im audioCb (nach usbAudioPush, kein Echo), Aufnahme `pcRec*` → `savePcRecording` samples/pc/pc-NN.wav, SET „PC-Ton über R36S“ (`pc_in`) / „PC-Ton als Sample aufnehmen“. Getrennte Lautstärken: `usbAudioSetGain(cfg.usbVol)` (SET „USB-Lautstärke“), intern stumm bei USB-Audio (`internal_on_usb`, `intMuted` → hwVolumeSet(0)). Lautstärketasten: evdev `gpio-keys-vol` → `hwVolumeSet` (Codec Master, settings `hw_volume`)

## Oberfläche Signalweg (Standard seit Übernahme nach main; Entwurf C „Zoom-Ebenen“ auf Branch ui-zoom aufgegeben)
- **Bedienkonzept (seit f0870ae in main):** Steuerkreuz + Tasten reichen, Sticks optional. L1/R1 = Regler (`slot`, leere Felder uebersprungen; Mixer: Zeile), L2/R2 = Seite im Ring der Gruppe (`gotoPage` mit `RING_TRK/RING_MIX/RING_PRJ`, `pageRing`; Kopfzeilen-Reiter in derselben Reihenfolge), SELECT tippen = Seitenkarte (`drawMenu/menuInput`, Raster `MAP_ROWS`, `mapPos/mapBox`, Beschreibung `PAGE_DESC`), START via `startTap()` (gestoppt: sofort Play; spielend: kurz = Stop beim Loslassen, halten > 250 ms = `eng.fill` solange gedrueckt), `startStop()`. Lock-Modus: L1/R1/L2/R2 bleiben frei, Trig kopieren/einfuegen = SELECT + L1/R1 bei `aHeld`. SELECT + L2/R2 = 16 Steps (frueher Spurlaenge). FX/CMP/MST: Steuerkreuz waehlt Regler; MIX: </> Kanal, ^v Zeile; PRJ: </> Feld, ^v Spur
- Einstellungen: Bereiche = Ueberschriften (`setIsHeader`, `setCatOf/setCatEnd`: PATTERN, SPUR n, AUDIO, MIDI, USB & PC, SAMPLES, SYSTEM), zwei Ebenen `setIn` (false: ^v Bereich, A/→ hinein, B verlaesst SET; true: ^v Eintrag im Bereich (Kreis), </> Wert, A Aktion, B zurueck zu den Bereichen), L1/R1 Bereich, Erklaerung `setHelp(i)` unten; Selbsttest prueft A/B
- Song-Export: Leiste unter der Matrix (`songExp`, `expField`, `expFrom/expTo` mit -1 = Ende, `expRange`), `startExport()` kopiert das Projekt in die zweite Engine `renderEng` (eigene Instanz, `Engine::init` baut globale Tabellen nur einmal), Thread `exportThread` rendert `songTicks()` Frames + Ausklang (bis 0,5 s still, max 8 s) nach `samples/rec/<Projekt>-song-NN.wav` (.part + rename); modal `drawExport` (B = abbrechen), Web-Sample-Reload waehrend des Exports aufgeschoben
- Oberfläche B: `drawSigB` Kopf mit 6 Spalten: SEQUENZ (TRIG/SEQ/ARP) | QUELLE (+ OSC bzw. zuletzt besuchter FM-Operator) → FILTER 1/2 → AMP/SENDS → INSERT | LFO 1-3 untereinander; Seitenkarte `MAP_ROWS` (Sequenz+Mod, Quelle, Klangweg, Live/Mix/FX-Busse, Projekt, nicht verfuegbare Seiten ausgeblendet); neue UI-Seiten nur hinten anfuegen (PG_SRC3..PG_FXC), Ring `RING_TRK`; Screenshot-Nummern: <20 Seite, 100+N neue Seiten, 60-64 FM/SYNTH/Bus/Wavetable-Editor, Erklärzeile `paramhelp.h`, Schrift UTF-8 (`nextGlyph`, Umlaute ß ° in font.h, `FONT_N`)

- Akkorde: ARP-Modus `ARP_CHORD` (5) → `Engine::cv[t][NCHORDV]` Zusatzstimmen; Hüllkurvenform `P_FCRV/P_ACRV` (FLT2-Slots 84/85, v11, Preset hdr[6]=2)
